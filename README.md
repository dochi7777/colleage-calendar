# 몽글플랜

몽글플랜은 대학생의 수업, 과제, 대외활동과 동아리 일정을 한곳에서 관리할 수 있는 웹 기반 시간 관리 서비스입니다.

하늘색을 중심으로 한 색상과 손글씨 느낌의 한글 폰트, 리본과 단추 장식, 도트 배경을 사용해 귀엽고 포근한 문구류 감성으로 디자인했습니다. 노트와 연필을 든 2등신 대학생 캐릭터도 화면 크기에 맞춰 전신이 보이도록 배치했습니다.

## 주요 기능

### 오늘

- 오늘 예정된 수업, 대외활동과 동아리 일정을 시간순으로 확인할 수 있습니다.
- 각 일정을 바로 수정하거나 삭제할 수 있습니다.
- 다가오는 과제의 완료 여부를 체크할 수 있습니다.
- 완료한 과제도 목록에서 사라지지 않고 체크 상태와 완료 표시가 유지됩니다.

### 시간표

- 월요일부터 금요일까지의 주간 수업 시간표를 확인할 수 있습니다.
- 수업 이름, 날짜, 시작 시간, 요일, 수업 길이와 강의실 메모를 등록할 수 있습니다.
- 등록된 수업을 시간표에서 직접 수정하거나 삭제할 수 있습니다.

### 대외활동

- 공모전, 서포터즈 등 대외활동의 일정과 상태를 카드 형태로 관리할 수 있습니다.
- 기존 활동을 수정하거나 삭제하고 새로운 활동을 추가할 수 있습니다.

### 동아리

- 정기 모임, 답사 등 동아리 일정을 등록하고 관리할 수 있습니다.
- 동아리 일정을 수정하거나 삭제할 수 있습니다.
- 별도의 메모장에 준비물이나 아이디어를 자유롭게 기록할 수 있습니다.

### 과제

- 과제를 진행 중과 완료 상태로 구분해 확인할 수 있습니다.
- 체크박스로 과제 상태를 변경할 수 있습니다.
- 전체 과제 진행률과 남은 과제 수를 확인할 수 있습니다.
- 과제의 내용과 마감일을 수정하거나 삭제할 수 있습니다.

## 데이터 저장

등록한 일정과 과제 상태, 동아리 메모는 브라우저의 `localStorage`에 자동으로 저장됩니다. 같은 브라우저에서 다시 페이지를 열면 이전 내용이 유지됩니다.

브라우저 데이터를 삭제하거나 다른 기기 또는 브라우저에서 접속하면 저장된 내용이 공유되지 않습니다.

## 실행 방법

별도의 설치나 빌드 과정이 필요하지 않습니다.

1. `dist/index.html` 파일을 웹 브라우저로 엽니다.
2. 상단 메뉴에서 오늘, 시간표, 대외활동, 동아리, 과제 화면을 이동합니다.
3. 각 화면의 추가 버튼을 눌러 새로운 일정을 등록합니다.

로컬 웹 서버를 사용하는 경우 프로젝트 폴더에서 다음과 같이 실행할 수 있습니다.

```bash
ruby -E UTF-8:UTF-8 -run -e httpd dist -p 4173
```

실행 후 브라우저에서 `http://127.0.0.1:4173/`에 접속합니다.
